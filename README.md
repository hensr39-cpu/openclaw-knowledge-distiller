## 🔍 What is openclaw-knowledge-distiller?

openclaw-knowledge-distiller is a simple app designed to turn YouTube and Bilibili videos into easy-to-read knowledge articles. It uses speech recognition and AI to summarize spoken content and organize it clearly. You don’t need to know coding or use complex tools. Just pick a video, and openclaw-knowledge-distiller will help you get useful notes and summaries quickly.

This software runs on your own computer, which means your data stays private. It uses local machine learning models to handle speech-to-text and summarize information. It also offers a server for advanced AI agents if you want to explore more features later.

## 📋 How to Use openclaw-knowledge-distiller

### Convert Videos into Articles

1. Copy the URL of a YouTube or Bilibili video you want to convert.
2. Paste the URL into the input box on the app’s home screen.
3. Click the "Start" button to begin processing.
4. The app will:
   - Download the video audio.
   - Use speech recognition to turn speech into text.
   - Summarize the key points using AI.
5. When done, it shows the text article on screen.
6. You can save the article as a text file or PDF for later.

---

### Using Local AI Models

openclaw-knowledge-distiller uses the Qwen3-ASR system to handle speech recognition inside your computer. This means it doesn’t upload your audio anywhere else. It also runs an AI summarizer locally to generate clear notes.

If you want, you can connect to the MCP server for advanced AI tasks like interacting with Claude Code or managing agents in Open CLAW, but this is optional.

## 🛠 Settings and Options ⚙️

The app lets you customize how it works:

- **Language selection:** Choose between Mandarin (普通话) and English to improve recognition.
- **Summarization level:** Pick brief, balanced, or detailed summaries.
- **Save format:** Choose to save articles as `.txt`, `.md`, or `.pdf` files.
- **Download folder:** Set where videos and output files are saved on your PC.
- **Auto-start server:** Enable or disable the MCP server on launch.

Adjust these from the “Settings” menu accessible at the top right of the app window.

## 🛠 Troubleshooting

If the app does not run or crashes:

- Restart your computer and try again.
- Make sure you have the latest Windows updates.
- Check that your antivirus isn’t blocking the app.
- Verify your internet connection for video downloads.
- Allow the app through the Windows firewall if prompted.

If transcription seems wrong or summaries are poor:

- Try a clearer video with good sound quality.
- Choose the correct language in settings.
- Use short videos (under 30 minutes) for better results.
